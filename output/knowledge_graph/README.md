# Knowledge Graph Outputs

This directory contains the seven current KG projects:

- `viet_full_unredacted`
- `cib_full_unredacted`
- `cib_full_redacted`
- `iran_full_unredacted`
- `fisc_full_unredacted`
- `fisc_full_redacted`
- `canberra_full_unredacted`

Each project is produced by
`scripts/knowledge_graph/kg_scripts/run_pipeline.py` and contains extraction,
alias, canonicalized extraction, graph, and Stage C task evidence boundaries.
See `docs/KNOWLEDGE_GRAPH_MANUAL.md` for the authoritative contract.
